Como configurar a conexão com a Twitch
  1. Abra o console de aplicações da Twitch e registre uma aplicação. A conta precisa de autenticação em duas etapas.
  2. Use a categoria Browser Extension, se disponível. Esta extensão usa o fluxo OAuth implícito; mantenha o tipo Confidential para esse fluxo. Cadastre exatamente esta URL de redirecionamento:
  3. Copie o Client ID para o campo acima, salve e clique em Conectar Twitch. Não gere nem cole Client Secret: ele não é usado pelo fluxo implícito.

A conexão pede somente identificação básica; não acessa seu chat. O token fica no armazenamento local desta extensão. Quando expirar, conecte novamente.

YouTube

Um lugar para acompanhar todos os canais.

Aceita @identificador, link com @ ou ID do canal (UC…). Até 100 canais.

Sem chave de API: consultamos a página pública de live do canal. Transmissões privadas, exclusivas para membros, com restrição de idade ou bloqueadas pelo YouTube podem não ser detectadas. Estreias e lives agendadas não geram avisos antes de começar.

Se o YouTube não confirmar um @identificador, use o endereço no formato /channel/UC…. Erros de consulta aparecem no painel da extensão.
